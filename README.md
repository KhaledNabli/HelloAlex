# HelloAlex

A small personal greeting page built from a 2016 Gulp/Bower web-app scaffold. The page displays a timer and a short message.

## Historical development setup

The original workflow used Node.js 4+, Gulp 3, Bower, Bootstrap, and jQuery. A typical setup was:

```bash
npm install
bower install
gulp serve
```

Modern Node.js versions are unlikely to run this toolchain without changes.

## Status

This repository is an unmaintained personal experiment and is retained only as a historical snapshot. It is not intended for production use.
